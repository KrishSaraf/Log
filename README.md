# Log

All-in-one health platform for Krish — activity, workouts, vitals, sleep,
nutrition, trends, and connections (HealthKit / Health Connect / Google Fit).

The exercise library is one module, not the whole product.

## Apps

- **dashboard/** — Next.js health home (Today, workouts, nutrition, metrics, connections)
- **ios/Log** — SwiftUI client with HealthKit
- **artifacts/lyfta-exercises** — Exercise library web module
- **artifacts/api-server** — Express API for the exercise catalogue

## Brand

Charcoal surfaces + electric lime (`#c6ff00`) accent across web and iOS.
